## Детали этапов

### Этап 2. Домен молитв ✅ (2026-11-15)
- Сущности `Wish`, `Rarity`, `ItemKind`, `BannerCode`, `WishTime`; пулы баннеров с общим счётчиком (`PoolDefinition`).
- `PityTracker`: счётчики 5★/4★, номер молитвы по гаранту, 50/50, серия проигрышей, Capturing Radiance.
- `StatisticsService` + команда `get_game_statistics`: карточки баннеров, итоги по игре, примогемы.
- Vitest подключён раньше плана: тесты форматирования, подстановки параметров, логики статуса 50/50.
- Правила и согласованные решения — в [genshin-rules.md](genshin-rules.md).

### Этап 3. SQLite
- Крейт `rusqlite` (bundled) или `sqlx` — выбор на этом этапе.
- Файл `data/wish-counter.sqlite`, миграции, индексы по (игра, баннер, время).
- `WishRepository` — порт в `application`, реализация в `infrastructure`.
- Настройки остаются в `settings.json`.

### Этап 4. Справочные данные
- Источник: данные репозитория Paimon.moe (`MadeBaruna/paimon-moe` на GitHub),
  чтобы ID совпадали при импорте. Запасные: Project Amber, genshin-db.
- Снимок данных встраивается в сборку, поэтому приложение работает офлайн.
  Онлайн-обновление идёт в `data/cache/`, картинки скачиваются по требованию.
- Проверить лицензию и условия использования источников.

### Этап 5. Интерфейс и тесты фронтенда
- Таблица молитв (пометки уже считает `annotate_wishes`) (виртуализация для тысяч строк, ленивые картинки), фильтры.
- **Тесты фронтенда:** Vitest уже подключён (этап 2), тесты лежат в `*.test.ts` рядом с кодом.
  Осталось покрыть `themes/registry`, `state/*` (с подменой `Backend`) и компоненты (@testing-library/svelte).

### Этап 6. Импорт и экспорт
- 📌 **Напомнить пользователю прислать файл экспорта из Paimon.moe**, чтобы сверить формат.
- UIGF v4 — общий стандарт для Genshin, HSR и ZZZ.

### Этап 7. Импорт из игры
- Чтение `output_log.txt` → путь к игре → `webCaches/<версия>/Cache/Cache_Data/data_2`
  → ссылка с `authkey` → API истории молитв с паузами между запросами.
- `authkey` не логируется, не сохраняется на диск и скрывается в интерфейсе.
- Подробнее — в [security.md](security.md).
