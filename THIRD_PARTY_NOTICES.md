# Сторонние данные и лицензии

## Paimon.moe — справочные данные Genshin Impact

Справочник `crates/games/genshin/data/reference.json` (персонажи, оружие, расписание баннеров,
русские названия) создан из данных репозитория
[MadeBaruna/paimon-moe](https://github.com/MadeBaruna/paimon-moe) командой `cargo run -p data-sync`.
Картинки персонажей и оружия скачиваются из того же репозитория.

Genshin Impact и связанные с ней материалы (имена, изображения) принадлежат HoYoverse.
